# VASUDHARA — The Living Loom

Concept prototype of a sustainable Indian heritage fashion house. A single static page: no build step, no dependencies.

## Publish on GitHub Pages
1. Put these files in the **root** of a GitHub repository (public, unless your plan supports private Pages).
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
3. Your site will appear at `https://<username>.github.io/<repo>/` within a few minutes.

## Files
- `index.html` — the whole site (HTML, CSS and JS in one file)
- `404.html` — custom not-found page
- `.nojekyll` — tells GitHub Pages to serve files as-is

Products, prices and profiles are illustrative sample data; no orders or payments are processed.
